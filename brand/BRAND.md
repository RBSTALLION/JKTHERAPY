# The Rebuild Room Rehabilitation: brand kit

Logo is light grey/white with a lime accent, made for dark backgrounds.

## Files
- `logo-original.png`: the logo as supplied (transparent background)
- `logo-full.png`: mark + wordmark, trimmed (use in headers, login, splash)
- `logo-mark.png`: the mark only, trimmed (use where space is tight)
- `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`, `favicon-32.png`: app icons on the brand background
- `splash-1170x2532.png`: iPhone splash

## Colours
| Token | Hex | Use |
|---|---|---|
| background | `#111315` | page background, PWA background_color |
| surface | `#1B1E21` | cards, panels, sidebar |
| surface-2 | `#25292D` | inputs, hover, raised items |
| border | `#2F3438` | dividers, outlines |
| text | `#F2F2F0` | primary text (matches the logo grey) |
| text-muted | `#A3A8AD` | secondary text |
| accent | `#B3D427` | primary buttons, links, active states, PWA theme_color |
| accent-hover | `#C4E04A` | button hover |
| on-accent | `#111315` | text on lime buttons |
| danger | `#E5534B` | errors, cancel |
| warning | `#E8A33D` | warnings |
| success | `#B3D427` | success (same as accent) |
